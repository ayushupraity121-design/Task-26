# Sales Data Visualization - Task 26 📈

This project is part of the AI & ML internship track (Day 26), focused on learning how data visualization helps interpret numerical and categorical data using Python.

---

## 🚀 Objectives
- Learn how to load and preprocess datasets using **Pandas**.
- Create categorical comparisons using **Matplotlib** bar charts (`plt.bar()`).
- Analyze trends over time using **Matplotlib** line charts (`plt.plot()`).
- Derive meaningful business insights from visual data.

---

## 🧰 Tools & Libraries
- **Python** (v3.8+)
- **Pandas** (Data manipulation and aggregation)
- **Matplotlib** (Data visualization)
- **Jupyter Notebook / VS Code** (Interactive development environment)

---
